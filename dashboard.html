Trainingsplanung

Sammle Bausätze, die sich bei echten Kunden bewährt haben, bau daraus den Plan für deinen Kunden und gib ihn als Plan-Code aus.

Nur ein Kürzel wie „TS-07“, nie Namen oder Gesundheitsangaben. Wer dahinter steckt, weißt nur du. Bausätze, Pläne und Stände liegen auf deinem Server (nur mit deinem Admin-Token erreichbar) und sind auf jedem Gerät gleich; „Alles als Datei sichern“ (unten) bleibt für deinen Rechner.

Bausätze

Ziehen auf den Plan oder „Einsetzen“ und dann auf die Stelle tippen. Ein Bausatz ist eine Kopiervorlage: ändern ändert keine ausgegebenen Pläne.

Für neue Codes an Kunden: ein eigenes Kürzel eintippen (optional) und dann auf "Zufällig ergänzen" tippen - hängt automatisch unerratbare Zeichen an, damit niemand fremde Trainings-Codes durchprobieren kann.

Erscheint einmal beim Öffnen des Codes, und wieder, sobald du den Text änderst. Gilt für jeden Code-Typ (auch Übersichten und JSON).

Ohne Datum gilt der Code unbegrenzt. Nach dem Ablauf sieht der Kunde einen Hinweis, sich an dich zu wenden. Plätze zählen Geräte: jedes Gerät, das den Code zum ersten Mal öffnet, belegt einen Platz.

Dieser Code nutzt eine Programmübersicht (mehrere Programme) oder ein Format, das der Baukasten noch nicht abbildet (z.B. Zirkel, Kraftplan oder Kombi) - bitte über den JSON-Tab bearbeiten.

Der Code landet in der App automatisch im passenden Bereich.

Weitere Einzelübungen (cross-modal, cone-tap, …) sowie periph-flash (Periphere Wahrnehmung, NAT) funktionieren im selben blocks-Format, aber nur hier im JSON-Tab - der Code landet dann automatisch auf der Startseite des jeweiligen Bereichs (NAT bei periph-flash, sonst Visuelles Training). Programmübersichten mit mehreren Programmen: {"type":"bundle","name":"…","programs":[{"label":"…","blocks":[…]}, …]}.

Andere Bereiche brauchen einen eigenen type: Krafttraining-Plan {"type":"workout-plan","name":"…","blocks":[…]} (Blockformat wie im Krafttraining-Baukasten, gleiche Feldnamen) bzw. {"type":"workout-bundle","programs":[…]}. Bewegungsprogramm (Reaktionstraining) {"type":"movement-plan","name":"…","movements":["armL-heben","armR-heben","legL-strecken",…],"bpm":90,"durationMin":8,"preview":3,"mirror":true,"showLabel":true} (mind. 2 Bewegungen aus den 8 Grund-IDs: armL/armR/legL/legR jeweils -heben/-strecken) bzw. {"type":"movement-bundle","programs":[…]}. Ausdauer-Einheit {"type":"cardio-plan","name":"…","items":[{"activity":"joggen","durationS":600,"label":"","interval":null}, …]} (activity aus joggen/rad/cross/rudern/walking/treppe/schwimmen, interval optional {"onS":30,"offS":30} - die Zusatzaufgabe während des Ausdauertrainings bleibt eine reine Klienten-Einstellung, kein Coach-Feld) bzw. {"type":"cardio-bundle","programs":[…]}. Vorlagen für „Eigenes Training“ {"type":"free-template","name":"…","trainings":[{"kind":"list","title":"Mobilisation","note":"…","items":[{"text":"Schultern kreisen","s":30}]},{"kind":"timer","title":"Eisbad","minutes":3},{"kind":"check","title":"Journal"}]} (kind check = Abhaken, timer = Mit Zeit mit minutes 1-60, list = Checkliste mit Punkten, s 0-600 Sekunden, 0 = selbst abhaken). Positionen merken/Blitz-Raster/Flash-Speicher-Test/MOT (NAT) sowie der Test-Bereich haben noch keinen Code-Typ. Neuro-Aktivierung: Freischalten {"type":"neuro-unlock","name":"…"} (mit "lock":true wieder verbergen), Spezialübung als Kombi-Code {"type":"combo-program","name":"…","blocks":[{"domain":"neuro","ex":"vibration","prefs":{"stepS":20,"reps":1,"takt":false,"bpm":60}}]} (ex aus vibration/ball-fuss/ball-hand/gelenke; Neuro-Bausteine dürfen auch zwischen anderen Kombi-Bausteinen stehen).
