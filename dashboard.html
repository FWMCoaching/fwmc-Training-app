Für neue Codes an Kunden: ein eigenes Kürzel eintippen (optional) und dann auf "Zufällig ergänzen" tippen - hängt automatisch unerratbare Zeichen an, damit niemand fremde Trainings-Codes durchprobieren kann.

Erscheint einmal beim Öffnen des Codes, und wieder, sobald du den Text änderst. Gilt für jeden Code-Typ (auch Übersichten und JSON).

Ohne Datum gilt der Code unbegrenzt. Nach dem Ablauf sieht der Kunde einen Hinweis, sich an dich zu wenden. Plätze zählen Geräte: jedes Gerät, das den Code zum ersten Mal öffnet, belegt einen Platz.

Dieser Code nutzt eine Programmübersicht (mehrere Programme) oder ein Format, das der Baukasten noch nicht abbildet (z.B. Zirkel, Kraftplan oder Kombi) - bitte über den JSON-Tab bearbeiten.

Der Code landet in der App automatisch im passenden Bereich.

Gültige exercise-Werte im Baukasten: vt-color, vrw-original, 4-straight, 4-diag, 8-solo, 8-vrw, stroop-classic, stroop-bg. Weitere Einzelübungen (cross-modal, cone-tap, …) sowie periph-flash (Periphere Wahrnehmung, NAT) funktionieren im selben blocks-Format, aber nur hier im JSON-Tab - der Code landet dann automatisch auf der Startseite des jeweiligen Bereichs (NAT bei periph-flash, sonst Visual Training). Programmübersichten mit mehreren Programmen: {"type":"bundle","name":"…","programs":[{"label":"…","blocks":[…]}, …]}.

Andere Bereiche brauchen einen eigenen type: Workout-Plan {"type":"workout-plan","name":"…","blocks":[…]} (Blockformat wie im Workout-Baukasten, gleiche Feldnamen) bzw. {"type":"workout-bundle","programs":[…]}. Bewegungsprogramm (Movement) {"type":"movement-plan","name":"…","movements":["armL-heben","armR-heben","legL-strecken",…],"bpm":90,"durationMin":8,"preview":3,"mirror":true,"showLabel":true} (mind. 2 Bewegungen aus den 8 Grund-IDs: armL/armR/legL/legR jeweils -heben/-strecken) bzw. {"type":"movement-bundle","programs":[…]}. Cardio-Einheit {"type":"cardio-plan","name":"…","items":[{"activity":"joggen","durationS":600,"label":"","interval":null}, …]} (activity aus joggen/rad/cross/rudern/walking/treppe/schwimmen, interval optional {"onS":30,"offS":30} - die Zusatzaufgabe während Cardio bleibt eine reine Klienten-Einstellung, kein Coach-Feld) bzw. {"type":"cardio-bundle","programs":[…]}. Positionen merken/Blitz-Raster/Flash-Speicher-Test/MOT (NAT) sowie der Test-Bereich haben noch keinen Code-Typ.

Optionale Video-Links (nur beim Standard-/Bundle-Typ): introVideo (Programmebene, vor Start), endVideo (Programmebene, nach der letzten Übung), videoAfter (pro Block, läuft nach dieser Übung) - reine URL-Strings, Abspielung in der App folgt noch.
